A one-screen controlling cockpit that shows how 11 cost centres (MPK, Miejsca Powstawania Kosztów) used their annual budget.

Managers and controllers can compare budget against actual spending for the whole organisation, a single department, one cost category or one month, and drill down from high-level cost groups to individual analytical accounts.

The project was the final assignment for a Power Pivot course. It met every mandatory requirement, added analytical features beyond the brief, and received the top grade (5.0).
